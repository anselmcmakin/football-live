# Football Live (unofficial)
Phone/TV web app for college football and the NFL: live scores ticker, live field with ball spot, line to gain and drive chart, follow-your-team, and a synthetic test game.
Data comes from ESPN's public scoreboard/summary feeds, fetched directly by each visitor's browser. Team logos load from ESPN's CDN at runtime and are not included here.
Unofficial fan project. Not affiliated with ESPN, the NCAA, the NFL, or any school or team.
